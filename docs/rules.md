# 逆五子棋规则

逆五子棋(连五者输)在五子棋基础上反转胜负条件:**先连成五子的一方判负**。

## 基本规则

- 棋盘 15×15,黑先(引擎常量 `BLACK=1`、`WHITE=2`、`EMPTY=0`)。
- 每一步(step)二选一:
  - **落子**:在空位放己方棋子,本回合结束;
  - **移子**:同一方连续两个步,共属一个回合:
    1. **占领**:把己方棋子放到对方棋子所在格,对方棋子被拿离棋盘;
    2. **安置**:把拿起的对方棋子沿 8 个方向之一直线放到连续空位(路径不得受阻)。
- 平衡规则:白棋前 `white_restrict_turns` 个回合不能移子(默认 2)。
- 判负:连成五子的一方判负;和棋:棋盘无空位且无人连五。
- 自杀手(走出后自己立刻连五)按规则判负;`mask_suicide=1` 时在合法掩码中剔除
  (AI 对局默认开启,避免 AI 主动自杀);引擎对局可关闭以与 C++ 原版行为一致。

## 配置项(GameConfig)

| 字段 | 默认 | 含义 |
|---|---|---|
| `board_size` | 15 | 棋盘大小(当前实现固定 15) |
| `white_restrict_turns` | 2 | 白棋前 N 个回合禁止移子 |
| `loss_start_turns` | 8 | 连五判负检查从第 N 手(step)起生效;纯性能优化,0 不改变结果 |
| `mask_suicide` | True | 是否在合法掩码中剔除自杀着 |

## 动作空间(225)

动作 = "在某格落子",`idx = r*15+c`(0..224),语义随状态阶段变化:

- **普通回合**:空位 → 落子;对方棋子位且存在可安置路径 → 占领(移子第一步);
- **安置回合**:沿 `pending` 射线可达的空位 → 把手中对方棋子放到该格。

方向与距离信息隐含在目标格坐标中,与"方向-距离"编码完全等价,但动作空间缩小
100 倍以上,网络输出、MCTS 节点与训练数据全部受益。

判负检查:占领步查己方连五(判己负),安置步查对方连五(判对方负)。

## 状态字段

- `move_count`:已完成的步数;
- `turn_count`:已完成的回合数(移子占 2 步但只算 1 回合);
- `white_turns`:白棋已完成的回合数(限制规则用);
- `pending`:`-1` 表示无"手中棋子";否则为被拿起的对方棋子原位(平铺索引),
  此时轮到同一位玩家走"安置"步。

实现见 `src/antifive/reversegomoku.py`(纯 numpy)与
`src/antifive/training/reverse_gomoku_torch.py`(批量 GPU 镜像)。
