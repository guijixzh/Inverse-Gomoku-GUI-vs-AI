# 棋谱格式(.afg)

`.afg` 为 UTF-8 纯文本格式,人类可读、可版本管理、可供行为克隆训练直接解析。
着法按引擎的"步"记录:普通落子 = 1 个着法,移子 = 2 个着法(占领 + 安置)。

## 格式

```
[AntiFive 1.0]                              # 格式版本
[Config 15x15 white_restrict=2 loss_start=8 mask_suicide=1]
[Result 黑胜|白胜|和棋|未完|黑认输|白认输]
[Moves 34]                                  # 着法数(信息项,解析时忽略)
moves:
O5 O4 O7 A4 ...                             # 着法序列,'#' 后为注释
[Analysis 34]                               # 可选:逐手分析数据
1 50.0 H8 J8:48.5 K8:47.2 L8:46.1
2 47.3 K8 ...
```

## 说明

- **坐标**:列字母 A-O + 行数字 0-14,与 GUI 棋盘标注一致(`O5` = 第 15 列第 6 行);
- **[Analysis] 行**:`手数 当前方胜率 最佳着法 [候选着法:胜率 ...]`
  (候选为 GTP 坐标:百分比);
- **认输局**:着法照常记录(棋盘上不出现五连),`[Result]` 用
  `黑认输`/`白认输` 标注认输方(黑认输 = 白胜,白认输 = 黑胜);
  载入或复盘跳到原谱末手时,按该结果补标认输终局;
- **解析容错**:允许缺省 `[Config]`/`[Result]`/`[Analysis]` 头;
  非 `[` 开头的行均视为着法序列。

## 示例

本仓库 `data/samples/` 提供了三个示例棋谱:

| 文件 | 结果 |
|---|---|
| `sample_black_win.afg` | 黑胜 |
| `sample_white_win.afg` | 白胜 |
| `sample_kill.afg` | 含杀棋局面 |

读写实现见 `src/antifive/record.py`;GUI 中 `S` 保存、`L` 读取。
